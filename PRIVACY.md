# Privacy

The public site is a static informational website hosted through GitHub Pages. This version does not include user accounts, forms, cookies, advertising, analytics, behavioral tracking, or a first-party database.

GitHub may process technical request information, such as an IP address and access logs, under its own privacy terms. Following an external link or sending email may expose information to the relevant third-party service under that service's own privacy terms.

If telemetry, forms, accounts, or analytics are added later, this notice should be updated before those features are enabled.
