## Browser scope

Testing uses the supported Chrome preview and a temporary same-origin iframe harness. The iframe creates a narrow CSS viewport and supports real mouse and keyboard interaction with the site. It does not emulate an iPhone, Safari, touch input, safe-area hardware or mobile browser chrome. The helper is removed before the final build and is not part of the commit.

At frame widths 320 and 390 px, the desktop browser reserves a 15 px scrollbar, yielding document client widths of 305 and 375 px while the menu is closed. These numbers must not be presented as physical-device results.

Observed before the CSS repair: document width 309 vs 305 px and 379 vs 375 px, both caused by the carousel margin; mobile menu link font size 12 px. The open overlay settles at opacity 1 with opaque RGB(4, 14, 24), covering the full frame. Screenshots captured during its short transition are not evidence of a persistent transparency bug.

After the final preview refresh, document and client widths match at both narrow sizes (305/305 px and 375/375 px); mobile navigation links compute to 22 px. The contact anchor lands at the top of its section with the menu closed and without a new application error.

Verified interactions:

- Menu opens and closes; Escape restores focus to the opener.
- Shift+Tab from the opener wraps to the contact link; Tab from the last link wraps back.
- Leaving the mobile breakpoint closes menu state and returning does not reopen it.
- `/demo` at frame width 320 px renders the stacked workload controls. Selecting wildfire changes its pressed state. Editing the illustrative scene count from 24 to 100 changes the raw collection from 38.40 to 160.00 GB and the result package from 86.4 to 360.0 MB, while retaining the illustrative label.
- `/publications` renders the two current reading cards and the updated two-archive boundary at frame width 320 px. The current Whitepaper v0.4 link opens the PDF and visibly renders its cover and following page in the browser.
- `/privacy` and `/disclaimer` render and expose the return links at frame width 768 px.
